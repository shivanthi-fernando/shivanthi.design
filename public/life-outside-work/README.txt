Drop your "life outside work" photos in this folder (jpg/jpeg/png/webp/avif/gif).
They show up automatically in the About section — no code changes needed.

Display order = alphabetical filename order. To control the order they
appear in, prefix filenames with numbers, e.g.:
  01-golden-gate.jpg
  02-hiking.jpg
  03-with-friends.jpg

Landscape and portrait photos are both fine — each card sizes itself to
the photo's own shape, no cropping.
