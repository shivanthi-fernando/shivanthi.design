Drop design shots in this folder (jpg/jpeg/png/webp/avif/gif).
They show up automatically in the fan carousel on the Home page — no
code changes needed.

Display order = alphabetical filename order. To control the order they
appear in, prefix filenames with numbers, e.g.:
  01-design.png
  02-design.png

For the cleanest look, keep a consistent aspect ratio across images —
the carousel doesn't crop, so mixed ratios will size differently.
